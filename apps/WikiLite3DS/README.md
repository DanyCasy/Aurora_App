# WikiLite3DS

An offline encyclopedia developed in C for AuroraOS on the Nintendo 3DS.

## 📖 Description

WikiLite3DS is an offline encyclopedia reader featuring **2,000 selected articles organized into 10 categories**.

The application is designed to work without an internet connection and uses both screens of the Nintendo 3DS to provide a convenient reading experience.

## ✨ Features

- **2,000 selected articles** available offline.
- **10 categories** covering different areas of knowledge:
  - Geography
  - History & Politics
  - Science
  - Technology & Computing
  - People
  - Arts & Culture
  - Film / TV / Music
  - Sports
  - Medicine & Biology
  - Economy & Society
- **Offline access** — no internet connection required.
- **Dual-screen interface** designed for the Nintendo 3DS.
- **Touchscreen support** for navigation and reading controls.
- **Physical button controls** for navigating categories and articles.
- **Paginated articles** with navigation between pages.
- **Article navigation** to move between entries or browse all articles.

## 🎮 Controls

### Home Screen

| Control | Action |
|---|---|
| D-Pad | Navigate through categories |
| A | Open the selected category |
| Touchscreen | Select a category |
| START | Open all articles |

### Article Reader

| Control | Action |
|---|---|
| A | Go to the next article |
| B | Go to the previous article |
| L | Go to the previous page |
| R | Go to the next page |
| START | Return to the category screen |
| Touchscreen | Navigate between pages and articles using the on-screen controls |

## 🛠️ Development

WikiLite3DS is written in **C** and uses the AuroraOS application interface.

The project includes:
- An embedded article database.
- A dual-screen graphical interface.
- Physical button input handling.
- Touchscreen interaction.
- Article and page navigation.

## ⚠️ Notes

- WikiLite3DS contains **2,000 selected articles**, not the entire contents of Wikipedia.
- The articles are stored locally, so an internet connection is not required to read them.
- The available content depends on the version of the application.
- The embedded article collection does not update automatically.
- Compatibility depends on the AuroraOS environment and the application build.
