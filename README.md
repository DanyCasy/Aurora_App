# Aurora_App

**Applications developed for AuroraOS on the Nintendo 3DS.**

Welcome to Aurora_App! 👋

This repository contains the source code and compiled binaries of the applications I develop for **AuroraOS**, an alternative operating system for the Nintendo 3DS.

This project is driven by my passion for technology and software development, with the goal of experimenting with new ideas, creating applications, and sharing my work with the AuroraOS community.

---

## ✨ About the Project

Aurora_App is a personal repository dedicated to developing and distributing my applications for [AuroraOS](https://github.com/TeamAuroraOS/AuroraOS).

Here you will find:

- 💻 **Source Code:** The files used to develop my applications.
- 📦 **Compiled Binaries:** Compiled application files, when available.
- 🔄 **Updates:** New versions, improvements, and bug fixes.
- 🧪 **Experimental Builds:** Features under development, when available.
- 📚 **Documentation:** Technical information and instructions for individual applications.

This repository will be updated progressively as new applications and improvements become available.

## 📱 Applications

Whenever possible, each application will have its own directory containing:

- Source code.
- Compiled binaries.
- Version information.

- Update notes.
- Known issues.

Applications will be added as they are developed and made available.

## ⬇️ Downloads

Compiled binaries will be published alongside their corresponding source code whenever available.

To download an application:

1. Open the directory of the application you want.
2. Locate the corresponding binary file.
3. Download the file.
4. Follow the application's specific installation and usage instructions for AuroraOS.

**Important:** Compatibility depends on the application, binary format, and supported execution environment. Always check the documentation before using a downloaded file.

Officially published versions will be available in the [Releases](../../releases) section when used.
